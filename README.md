# 🩺 Medical Report Explainer

An AI-powered web application that converts complicated medical report information into simple, easy-to-understand language.

## ✨ Features

- 📄 Upload medical reports in PDF format
- 📝 Paste report text manually
- 🤖 AI-powered report explanation
- 🧪 Test-wise result cards
- 📊 Shows values, units, and reference ranges
- ⚠️ Highlights important observations
- 💬 Ask questions about the uploaded report
- 🌐 English, Telugu, and Hindi support
- 📋 Copy AI explanation
- ⬇️ Download explanation as a text file
- 📱 Responsive design
- 🧪 Sample report for testing

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- PDF.js
- Gemini API
